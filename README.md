## 章节

1. 市级人才支持（4 项）：青年人才认定、安居补贴、过渡性住房、来深礼包
2. 就业类补贴（5 项）：求职创业、灵活就业社保、个人社保、职业技能提升、工会圆梦计划
3. 税收优惠（9 项）：六项专项附加扣除、个人养老金、年终奖单独计税、年度汇算、重点群体扣减
4. 住房类支持（6 项）：青年驿站、深梦扬帆、保租房（政府/社会）、公租房、公积金租房提取
5. 创业类补贴（6 项）：免租空间、初创补贴、场租、社保、带动就业、担保贷款
6. 区级入户补贴（9 项）：福田、南山、龙华、龙岗、宝安、坪山、光明、大鹏、罗湖
7. 生活优惠（2 项）：公共交通、公共体育场馆

## 收录标准

只收“稳定有效、有实际物质收益、无需额外付费”的项目。已失效的市级租房和生活补贴、基层就业补贴，以及不定期发放的消费券、需付费购买的优惠均未收录。

> 政策以官方当期文件为准；本指南用于筛选，不替代窗口答复。
